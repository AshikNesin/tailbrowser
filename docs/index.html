How it works

Three steps, and your agent has a browser.

  1. Start the relay

    Run it once, on any machine in your tailnet. It binds to the Tailscale IP and prints what to paste where.

    $ npx tailbrowser relay

  2. Load the extension

    On the Chrome machine, load extension/ unpacked, click Find local relay or paste ws://mac-mini:8787, and share a tab.

  3. Run a snippet

    From any tailnet machine. The relay is found automatically and the session stays with you.

    $ npx tailbrowser -e 'await page.goto("https://example.com"); return await page.title()'
"Example Domain"

    Or give it to Claude Code, Cursor, or any MCP client:

    { "mcpServers": { "tailbrowser": { "command": "npx", "args": ["-y", "tailbrowser@latest", "--mcp"] } } }
Scope

You choose what agents can see.

Tabs I pick

Only the tabs you share from the popup. The default.

Allowlist

Tabs whose URL matches your patterns, attached as you browse.

Entire browser

Every tab, plus opening and closing tabs.

Tabs outside the scope do not exist for the agent. Asking for one returns a TB_SCOPE error. Narrow the scope and tabs detach at once.

Security

Private by design.

  • Tailnet onlyThe relay binds to your Tailscale IP. Nothing off the tailnet can connect.
  • Optional tokenTokenless on a personal tailnet; add --token when you share one.
  • Always visibleChrome shows its debugging banner on every shared tab. Dismiss it to unshare.
  • One-click revokeDrops the relay link and every attachment, and stays off after a restart.
